# Microservices-

Project topic: restaurant system. Three independent microservices: menu, reservation, bill. Implemented in Java, SPRING Boot. Config server, eureka, load balancing, validation, error handling, API Gateway - filters, authorization, authentication, routing. Resilience4j, Feign. REST endpoints, CRUD and more complex operations. MySQL database. Backend

Tema projekta: restoran sistem. Tri nezavisna mikroservisa: meni-service, rezervacija-service, racun-service. Mikroservisi medjusobno komuniciraju. RESTfull. Implementirano u Javi, Spring Boot. U projektu ukljuceni: config server i repo, eureka - naming server, load balancing, validacija, upravljanje izuzecima, API Gateway (rutiranje, autorizacija, autentifikacija), Resilience4j, OpenFeign. Implementirane jednostavne CRUD i slozenije operacije. Kreirana i koriscena MySQL baza podataka. Backend.
